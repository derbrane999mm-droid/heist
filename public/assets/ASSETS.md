# Third-party assets in public/assets

Format: `file/folder | source URL | author | license`. Index with notes and tile sizes: `manifest.json`.

Processing applied to all textures: resized to max 1024 px, re-encoded as JPEG (q85, normals q88 4:4:4). All `normal.jpg` files are OpenGL (+Y) convention, which is what three.js expects; where the source was DirectX (-Y) the green channel was inverted (marked "G flipped"). Other changes are listed per line. CC-BY and Apache-2.0 items require this attribution file (or equivalent credits) to ship with the game.

The first URL on each line is where the file was actually downloaded from (pinned commit or package version). "original" URLs point to the publisher's page and are built from the asset ID; those sites were not reachable when the assets were collected, so they are unverified.

Lines marked (!) have a weaker licence trail than the rest; see the note on that line.
